# skills

Коллекция скиллов Claude Code для автоматизации рутины.

## youtube-publish-bsk

Скилл выкладки видео в **YouTube Studio** через `bsk` (Tencent BrowserSkill — управление реальным Chrome из CLI + расширение BrowserSkill). Покрывает шортсы и длинные видео:

- заполнение **всех** полей формы загрузки: название, описание, теги (чипы через запятую), миниатюра (shadow-DOM хак `input#file-loader`), «Место съемки», COPPA;
- **отложенная публикация** (виджет расписания, ловушки VOM) и **немедленная** (кнопки в shadow DOM, ожидание обработки до 120 с);
- **плейлисты**: добавление через «Выбрать плейлисты», страница `/content/playlists`, создание плейлиста диалогом «Новый плейлист»;
- **переключение между залогиненными каналами** (несколько Google-аккаунтов в одном Chrome) и обход кэш-403 после смены аккаунта;
- разбор отказов: суточная квота загрузок, спасение залитого черновика, ложные диалоги подтверждения (правило: сверять рядом в списке / скриншотом).

Скилл написан под проект с обвязкой `scripts/publish_studio.mjs` + `data/youtube.json`
(очередь и идемпотентный state) — механику UI и лейблы формы можно применять отдельно.

Формат: стандартный `SKILL.md` (frontmatter `name` + `description`) — кладите
каталог скилла в `.claude/skills/` вашего проекта.
